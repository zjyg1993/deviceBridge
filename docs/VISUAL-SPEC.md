# DeviceBridge 主界面视觉规范

适用于 macOS 上的「设备列表」。尺寸使用 AppKit 点数，随系统显示缩放渲染。

## 窗口与分组

- 默认内容区为 720 × 700 pt，最小为 560 × 420 pt。标题、刷新按钮和全部分组共用纵向滚动区。
- 从上到下排列「显示器」「2.4G 设备」「硬盘」「通用」。卡片距滚动内容区两侧各 24 pt，圆角半径 12 pt。分组标题占 20 pt，标题起点距卡片顶部 32 pt，相邻分组之间留 28 pt。
- 窗口背景使用系统 `windowBackgroundColor`。卡片使用随外观变化的灰度填充，浅色为 0.96，深色为 0.17。文字使用系统的主、次、三级标签色，随浅色和深色外观切换。

## 文字与图标

| 元素 | 规格 |
| --- | --- |
| 窗口内容标题 | 22 pt，半粗 |
| 分组标题 | 13 pt，半粗 |
| 显示器、2.4G 设备和硬盘名称 | 13 pt，中等字重 |
| 2.4G 状态与更新时间 | 11 pt 次级标签色，更新时间使用 10 pt 三级标签色 |
| 电量 | 20 pt 等宽数字，右对齐 |
| 硬盘数据与 SMART 提示 | 11 pt，指标名和提示用次级标签色，指标值用主标签色 |
| 显示器、2.4G 设备和硬盘图标 | SF Symbols，28 pt 常规字重，放在 40 × 40 pt 图标框内，距卡片左侧 16 pt |

设备名称从卡片左侧 72 pt 开始。图标在各自行内垂直居中。已连接设备和硬盘使用次级标签色绘制图标，未连接设备使用三级标签色。硬盘统一用 `internaldrive` 图标。

## 卡片、分割线与数据

- 显示器和 2.4G 设备每行高 96 pt，硬盘每行高 120 pt。空分组卡片高 64 pt，硬盘空状态与设备名称对齐。
- 2.4G 设备和硬盘的行间分割线使用同一绘制方式。左侧缩进 72 pt，与名称对齐，右侧留 16 pt，线宽 0.5 pt。分割线浅色灰度为 0.88，深色为 0.28。仅相邻行之间绘制。
- 硬盘数据采用两列。第一行是总读取/总合并和已用/总计，第二行是温度和健康度，第三行是通电次数和通电小时。卷标放在磁盘名称后的括号内，所有硬盘使用相同图标。硬盘标题和数据均从卡片左侧 72 pt 开始，左侧图标列只显示图标。不可读值显示「—」。SMART 不可读时，在名称右侧同一行显示「此磁盘主控不支持读取SMART信息」。数值下方省去说明行。
- 长名称与数值可单行截断，并通过悬停显示完整内容。缩窄窗口时为 SMART 提示预留宽度。

## 原生控件

显示器的亮度与音量使用 macOS 滑块和百分比输入框，旁边显示独立桥接开关。2.4G 设备的「映射」开关位于刷新、删除图标按钮左侧，删除离线设备时使用附着在主窗口的原生确认框。支持弹出的硬盘在行末显示垂直居中的「弹出」按钮，距右侧 16 pt。「通用」使用系统弹出菜单选择更新周期，使用开关控制登录时启动。
